# Tsukimori — Akira és Miyako közös utcai Living CG forrásképek

A képek nem a GitHub main ágából származnak, hanem az eredeti chatben készült képfájlok változatlan másolatai.
Mindkettő 1672 × 941 (közel 16:9), PNG, ráégetett UI és felirat nélkül.

## Használati sorrend

- **01_USER_PREFERRED_REVIEW**: az a fekete garbós, rövid fekete szoknyás Miyako-változat, amelyet a tulajdonos kifejezetten kedvelt. Ez legyen az első Godot Living CG teszt alapja, ne a régi, formális kimonós beauty-reference.
- **02_LATEST_VARIANT_REVIEW**: későbbi, szinte ugyanilyen beállítású változat; további tulajdonosi jóváhagyás nem dokumentált, ezért csak alternatív REVIEW.

Mindkét képen Akira szemüveg nélküli, sötét kapucnis civil öltözéket visel; Miyako hosszú sötétbarna hajjal, arany hajdísszel és hétköznapi fekete ruhában áll a lámpafényes cseresznyevirágos utcán.

A képeket NE szerkeszd át, ne cseréld más jelenetre. Első mozgási próba: lassú kamera zoom/pan, finom részecskék, lámpafény. Önálló arc/haj deformáció csak külön rétegekkel. Nincs képre égetett VN-doboz; az UI külön Godot réteg.

Az itt szereplő két CG **REVIEW**, nem FINAL. A kép helyszíni folytonosságát külön ellenőrizni kell, különösen hogy Miyako első találkozása a házánál történik.
