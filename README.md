# Tsukimori — Zárt Világ

Első technikai vertical slice v0.0.1.

## Jelenlegi cél

Csak az első játékélmény alapját teszteljük:

**hegyi ösvény → Tsukimori kapuja → első anomália**

Ez még BLOCKOUT. Nem végleges grafika.

## Jelenleg működő alapok

- Godot 4.x projektstruktúra
- 3D CharacterBody3D játékos
- 3/4-es követőkamera
- WASD mozgás
- egyszerű hegyi út blockout
- torii / falukapu blockout
- belépési trigger
- minimális GameState flag-rendszer
- fejlesztői HUD

## Irányítás

- W/A/S/D — mozgás

## Fontos

A projektben szereplő primitív geometriák **PLACEHOLDER / BLOCKOUT** státuszúak.
Nem válhatnak automatikusan végleges assetté.

Következő fejlesztési feladat csak review után indul.
